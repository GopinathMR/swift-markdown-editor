# Changelog

## 0.1.0

Initial release of MarkdownEditor, a native macOS Markdown editor component for
SwiftUI apps.

- Single-pane editing with inline rendering and Markdown source revealed at the caret.
- TextKit 2 editing that preserves the underlying Markdown, with undo, find,
  spell checking, source mode, focus mode, and typewriter mode.
- Syntax-highlighted code, native LaTeX math, tables, diagrams, images, and document outlines.
- A SwiftUI view, editor controller, commands, preferences, themes, and host hooks.
- File loading, saving, change watching, conflict handling, and document export.
- A demo app with a built-in feature tour.

Requires macOS 14 or later and Swift 6.0 or later. Licensed under Apache 2.0;
bundled third-party resources retain their own licenses.
